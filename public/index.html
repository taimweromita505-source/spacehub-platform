REST API Reference

Stage and deploy web applications programmatically: 

# 1. Create a Private Staging Space
curl -X POST https://spacehub-platform.taimweromita505.workers.dev/api/agent/v1/spaces \
  -H "Authorization: Bearer YOUR_SH_PAT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "my-web-app",
    "visibility": "private",
    "files": {
      "index.html": "<!DOCTYPE html><h1>Hello</h1>",
      "style.css": "body { font-family: sans-serif; }",
      "script.js": "console.log(\"Ready\");"
    }
  }'

# 2. Update Staged Files
curl -X PUT https://spacehub-platform.taimweromita505.workers.dev/api/agent/v1/spaces/USERNAME/my-web-app/files \
  -H "Authorization: Bearer YOUR_SH_PAT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"files": {"index.html": "..."}}'

# 3. Deploy to Connected Host
curl -X POST https://spacehub-platform.taimweromita505.workers.dev/api/agent/v1/spaces/USERNAME/my-web-app/deploy-external \
  -H "Authorization: Bearer YOUR_SH_PAT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"provider": "cloudflare_pages", "visibility": "public"}'
PLATFORM OVERVIEW

How SpaceHub Works

A streamlined workflow for staging, testing, and launching modern web applications.

1. Private Staging Workspace

Every Space begins in staging mode with multi-file editing (index.html, style.css, script.js, and README.md) and live Desktop, Tablet, and Mobile viewport previews.

2. Granular Privacy Controls

Keep work-in-progress projects set to Private so only your account can access the source files or preview URL. Switch to Public when ready to share.

3. Bring Your Own Coding Agent

Connect Google Gemini, OpenAI-compatible models, or custom webhooks inside the workspace, or push code from external CLI agents via REST API.

4. Flexible Cloud Deployment

Deploy verified staging builds directly to Cloudflare Pages, GitHub Pages, Vercel, Netlify, or export a portable static bundle.
