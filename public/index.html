PROGRAMMATIC WORKSPACE & BYOK AGENT INTEGRATION

🤖 Bring Your Own Coding Agents via API

Connect your own coding agents in two ways: (1) plug your API key/endpoint into the In-Studio Coding Agent inside any Space's Workspace, or (2) generate a SpaceHub Agent API Key (sh_pat_...) so external CLI agents, scripts, or autonomous runners can create Spaces, push code to staging for you to preview, and deploy to your connected hosting service when ready.

🔑 Your SpaceHub Agent API Keys (sh_pat_...)

Use these Bearer tokens in external coding agents (Claude Code, Antigravity scripts, Cursor, CI pipelines) to push HTML/CSS/JS files into your staging workspace.

📡 External Coding Agent REST Endpoints

External agents authenticate with Authorization: Bearer sh_pat_... or X-Agent-Key: sh_pat_...: 

# 1. Create a Private Staging Space via Agent API
curl -X POST http://localhost:3000/api/agent/v1/spaces \
  -H "Authorization: Bearer sh_pat_demo_alex_agent_key_2026" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Agent Built Web App",
    "visibility": "private",
    "files": {
      "index.html": "<!DOCTYPE html><h1>Built by Agent</h1>",
      "style.css": "body { background: #090d16; color: #fff; }",
      "script.js": "console.log(\"Ready in staging!\");"
    }
  }'

# 2. Push Updated Files to Staging Workspace (Check before launch)
curl -X PUT http://localhost:3000/api/agent/v1/spaces/alex/agent-built-web-app/files \
  -H "Authorization: Bearer sh_pat_demo_alex_agent_key_2026" \
  -H "Content-Type: application/json" \
  -d '{"summary": "Refined hero layout", "files": {"index.html": "..."}}'

# 3. Deploy to Connected Hosting Service when verified
curl -X POST http://localhost:3000/api/agent/v1/spaces/alex/agent-built-web-app/deploy-external \
  -H "Authorization: Bearer sh_pat_demo_alex_agent_key_2026" \
  -H "Content-Type: application/json" \
  -d '{"provider": "vercel", "visibility": "public"}'

📐 How SpaceHub Works: Staging Workspace + BYO Coding Agents + Connect Hosting

Inspired by Hugging Face Spaces, SpaceHub gives every user a private staging studio to build and verify their website first, then buy or connect external hosting when ready to launch:

1. Work & Check in Staging First

Every Space starts in Staging Draft mode with multi-file editing (index.html, style.css, script.js, and README.md YAML metadata) and an interactive viewport tester (Desktop, Tablet, Mobile) so you can verify how your website looks before paying for or connecting hosting.

2. Privacy Option (Public vs. Private)

Toggle any Space to Private (🔒) so only you can view the code or preview it. Unauthorized visitors receive a 404 Private Space lock screen.

3. Bring Your Own Coding Agent (BYOA)

Use the in-studio Coding Agent bar (Gemini 3.8 Flash / 4 Argon, Antigravity Agent, OpenAI-compatible, or Built-in Agent) or use sh_pat_... API keys from external CLI agents.

4. Buy or Connect Hosting to Launch

When you are ready to launch, buy a hosting plan ($5/mo Starter Edge, $15/mo Pro Cloud) or connect your existing Vercel, Netlify, GitHub Pages, Cloudflare Pages, or Custom Deploy Webhook to push your staged files live.
